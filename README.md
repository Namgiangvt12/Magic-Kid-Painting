# Magic Kid Painting (Color Kids) 🎨✨

**Magic Kid Painting** is a delightful, intuitive, and sensory-rich digital coloring app built with Flutter, designed expressly for kids aged 3 to 8 and trusted by parents.

---

## 🌟 Key Features

- 🎨 **Interactive Coloring Canvas**:
  - Smart Flood-Fill (bucket fill) with pixel-perfect boundary detection.
  - Smooth freehand brush strokes with multiple thickness options.
  - Child-safe eraser and responsive Undo / Redo mechanics.
  - Celebratory completion animation with star rewards, Dino cheers, and photo saving.

- 🦁 **Rich Theme Collections**:
  - Themes include: Animals, Dinosaurs, Vehicles, Fairy Tales, and Ocean.
  - Voice cues and search-free visual cards for pre-readers.

- 🪄 **AI Magic Sketch Converter**:
  - Interactive before/after split slider.
  - Transform favorite pet, toy, or family photos into clean coloring line-art.
  - Child-safe reward turn mechanism.

- 🖼️ **Little Artist Gallery**:
  - Filter artworks by "All", "Completed", or "In Progress".
  - Continue coloring anytime or delete with an adult-safe confirmation modal.

- 🔒 **Parental Gate & Safety (COPPA Compliant)**:
  - Random math challenge barrier to protect adult settings and external links.
  - Screen time management with eye-rest reminders.
  - Toggle background music and realistic sound effects (SFX).

- 🌐 **Full 6-Language Localization**:
  - 🇻🇳 Vietnamese (Tiếng Việt)
  - 🇺🇸 English
  - 🇯🇵 Japanese (日本語)
  - 🇰🇷 Korean (한국어)
  - 🇫🇷 French (Français)
  - 🇨🇳 Chinese (中文)

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (3.24.0 or higher)
- Android Studio / Xcode / VS Code
- Android or iOS device / emulator

### Run Locally
```bash
# Clone the repository
git clone https://github.com/Namgiangvt12/magic-kid-painting.git
cd magic-kid-painting

# Install dependencies
flutter pub get

# Run on connected device or emulator
flutter run
```

### Run Tests
```bash
flutter test
```
